# 字幕烧录

一个跑在本地的字幕烧录小工具：把视频和字幕文件拖进浏览器，调整字幕的位置、字号、样式与出现时间，确认后直接用 ffmpeg 把字幕烧进视频。

## 特点

- **预览与导出一致**：画布实时预览和导出的 ASS 字幕共用同一套字号、边距、对齐参数；暂停时默认叠加 ffmpeg 实际渲染出的校验帧，所见即最终效果。
- **自动保存**：样式、时间、文本调整自动写入本地 `data/workspace.json`，重启服务或刷新页面都会恢复上次状态。
- **样式不会被随便覆盖**：替换视频或字幕时保留已定样式；恢复默认样式需要手动确认。
- **零 npm 依赖**：后端只用 Node.js 原生模块，前端是原生 ES Module，不需要安装依赖。
- **浏览器播不了的视频**：自动生成 H.264 预览代理；导出仍然使用原始视频。

## 环境要求

- Node.js 18 及以上（已在 Node.js 24 上验证）
- `ffmpeg`、`ffprobe` 在 PATH 中
- `ffmpeg` 需要编译了 libass（`ffmpeg -filters` 中能看到 `ass` 滤镜）

可选环境变量：

| 变量 | 说明 |
| --- | --- |
| `PORT` | 服务端口，默认 `5178` |
| `DATA_DIR` | 数据目录，默认项目下的 `data/` |
| `FFMPEG_PATH` | ffmpeg 可执行文件路径 |
| `FFPROBE_PATH` | ffprobe 可执行文件路径 |

## 运行

```bash
node server/index.js
```

然后打开 `http://127.0.0.1:5178`。

## 使用

1. 把视频和字幕文件拖进窗口，或点击「导入文件」。
2. 在右侧调整字体、字号、描边/底板、阴影、对齐和边距。
3. 在「时间与文本」里调全局偏移，或逐条修改字幕起止时间与文字。
4. 点「导出视频」，选择画质后开始烧录；完成后可下载或打开导出目录。

空格键播放/暂停，`←` / `→` 跳 5 秒。导入 ASS/SSA 时只读取文本与时间，ASS 自带样式不会覆盖右侧已定样式。

支持视频：MP4 / MOV / M4V / MKV / AVI / WEBM / FLV / WMV / TS / MPEG 等。
支持字幕：SRT / ASS / SSA / VTT / TXT，自动识别 UTF-8、UTF-16、GB18030、Big5 编码。

## 预览一致性

- 播放和拖动时使用 Canvas 实时绘制，响应快。
- 暂停时（默认开启「精确预览」）用当前样式生成 ASS，并让 ffmpeg 渲染真实帧叠加在视频上。校验帧和导出走同一个 ASS 生成函数，因此样式、位置、时间和导出结果一致。
- 默认字体是「黑体（SimHei）」，这是 Windows 上 libass 与浏览器字宽最接近的中文字体；换用其他字体时，实时预览可能存在细微字宽差异，以「精确预览」帧为准。

## 数据目录

```
data/
  workspace.json   # 当前视频、字幕、样式、时间与播放位置
  media/           # 视频、字幕、预览代理的副本
  exports/         # 导出完成的 MP4
```

原始文件会被复制到 `data/media/`，所以之后移动或删除原文件不会影响恢复。

## 项目结构

```
server/             Node.js 服务与 ffmpeg 调用
public/             前端页面、样式和 ES Module
data/               运行时数据（已在 .gitignore 中忽略）
```
